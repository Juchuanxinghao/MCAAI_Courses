Bottom-up Estimating MethodBottom-up Estimating MethodThree-Point Estimating
•This method also known as PERTMethod (Program Evaluation and Review Technique).•Used when there is some degree of uncertainty about the work.•Uses following three types of estimates:  •Most Likely Estimate, which is based on the realistic-case scenario for the cost of the work item.•Optimistic Estimate, which is based on the best-case scenario for the cost of the work item.•Pessimistic Estimate, which is based on the worst-case scenario for the cost of the work item.

Earned Value Management (EVM)
Earned Value Management (EVM) is a methodology that combines scope, schedule, and resource measurements to assess project performance and progress.
It integrates scope baseline and cost baseline, along with the schedule baseline to form the performance management.

Prepared by: Ravish MaqsoodAll rights reserved. No slide or part to be reproduced or publishedon any platform without permission of the owner. 
Earned Value Management (EVM)Earned Value Management (EVM) develops and monitor 3 key dimensions for each work package and control account: 
1.Planned Value (PV)2.Earned Value (EV)3.Actual Cost (AC)
