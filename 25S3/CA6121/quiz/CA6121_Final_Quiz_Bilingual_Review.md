## 2. One-Page High-Yield Summary｜高频一页速记

- A **project** is a **temporary endeavor** to create a **unique product, service, or result**.  
  **项目**是为了创造**独特产品、服务或成果**而开展的**临时性工作**。

- Project management applies **knowledge, skills, tools, and techniques** to meet project requirements.  
  项目管理就是运用**知识、技能、工具和方法**来满足项目要求。

- PM always balances the classic triangle/trade-off: **time, cost, quality** (and often scope/risk/resources).  
  项目管理始终在平衡 **时间、成本、质量**（以及范围、风险、资源）。

- PMBOK 8 in this course emphasizes **6 principles + 5 focus areas**.  
  本课程里的 PMBOK 8 强调 **6 个原则 + 5 大关注领域**。

- AI in PM is about **workflow enhancement**, not just building AI products.  
  PM 中的 AI 强调**改进工作流**，不只是开发 AI 产品本身。

- Planning includes: **define activities → sequence activities → estimate durations → develop schedule**.  
  计划管理包括：**定义活动 → 排序活动 → 估算工期 → 制定进度**。

- **Critical path = zero float path**. Any delay on it delays the project.  
  **关键路径 = 浮时为 0 的路径**，其上任务延误会导致项目整体延误。

- EVM tracks **PV, EV, AC**, then derives **CV, SV, CPI, SPI, EAC**.  
  挣值管理用 **PV、EV、AC**，进一步计算 **CV、SV、CPI、SPI、EAC**。

- Quality = **fit for purpose** and **meeting customer expectations**.  
  质量就是**适用性**和**满足客户预期**。

- Risks are **uncertain events** affecting objectives; they can be known or unknown.  
  风险是影响目标实现的**不确定事件**，可分为已知风险与未知风险。

- A strong project manager needs **technical + leadership + management** competencies.  
  优秀项目经理需要兼具 **技术、领导力和管理能力**。

### 5.8 Schedule network diagram｜网络图
A schedule network diagram shows the logical relationships among activities.

### 5.9 Critical Path Method (CPM)｜关键路径法
CPM estimates the **minimum project duration** and determines scheduling flexibility.  
CPM 用于计算**最短工期**以及活动的**时间弹性**。

#### Core formulas｜核心公式
- `EF = ES + t`
- `LS = LF - t`
- `Float = LS - ES = LF - EF`

Where:
- ES = Early Start｜最早开始
- EF = Early Finish｜最早完成
- LS = Latest Start｜最晚开始
- LF = Latest Finish｜最晚完成
- Float = Slack｜浮时/时差

### 5.10 Float｜浮时
Float is the maximum permissible delay without affecting project completion.  
浮时表示任务在不影响整体完工时间的前提下可允许延迟的时间。

> **Key point｜关键点：** if a task has **zero float**, it lies on the **critical path**.  
> 若任务 **浮时为 0**，它就在 **关键路径** 上。

### 5.11 Resource management｜资源管理
Types of resources:
- Human resources｜人力资源
- Physical resources｜物理资源（设备、材料、设施等）

### 5.12 RACI Matrix｜RACI 责任矩阵
- **R** = Responsible｜执行者
- **A** = Accountable｜最终负责者
- **C** = Consulted｜被咨询者
- **I** = Informed｜被通知者

### 5.13 Resource optimization techniques｜资源优化技术
- **Resource Leveling**: balance resource loads, may extend schedule  
- **Resource Smoothing**: optimize usage without changing the critical completion date

### 5.14 Schedule compression｜进度压缩
- **Fast Tracking**: overlap activities, higher risk  
- **Crashing**: add more resources, higher cost

### 5.15 AI use in planning and scheduling｜AI 在计划与进度中的应用
- activity sequencing suggestions  
- milestone generation  
- critical path identification  
- forecasting delays  
- resource optimization and workload balancing  
- schedule scenario comparison

### 5.16 Worked mini-example｜计算例题（进度）
If an activity has:
- ES = 5 days
- duration = 4 days
- LF = 12 days

Then:
- EF = ES + t = `5 + 4 = 9`
- LS = LF - t = `12 - 4 = 8`
- Float = LS - ES = `8 - 5 = 3`

**Interpretation｜解释：** this task can slip by 3 days without delaying the project.  
该任务最多可延迟 3 天而不影响整体工期。

## 6. Lecture 4 — Cost Management, Forecasting, EVM｜第4讲：成本管理、预测与挣值管理

### 6.1 Four cost management processes｜成本管理四过程
1. Plan Cost Management｜规划成本管理
2. Estimate Costs｜估算成本
3. Determine Budget｜制定预算
4. Control Costs｜控制成本

### 6.2 Cost management plan components｜成本管理计划内容
- approach and process  
- roles and responsibilities  
- reporting format  
- units of measure  
- level of precision  
- level of accuracy  
- procedures and thresholds  
- EVM and performance management  
- currency and funding issues

### 6.3 Types of cost estimates｜成本估算类型
- Rough Order of Magnitude (ROM)｜粗略量级估算
- Definitive Estimate｜确定性估算

### 6.4 Estimate accuracy ranges｜估算精度范围
- Concept｜概念阶段：`±50%`
- Feasibility｜可研阶段：`±25%` or around `±20%`
- Basic Design｜基础设计：around `±20%`
- After Details｜详细设计后：around `±10%`
- Proposal Submission｜投标/提交方案：`±5% to ±10%`

### 6.5 Cost estimating methods｜成本估算方法

#### Top-Down Estimating｜自上而下估算
- uses historical information  
- fast and cheap  
- useful in early stage  
- lower accuracy

#### Bottom-Up Estimating｜自下而上估算
- uses WBS and work packages  
- more detailed and more accurate  
- slower and more expensive

### 6.6 Bottom-up sub-methods｜自下而下子方法
- **Direct Approach**: labor + materials + equipment + tools + overheads + profits + contingency
- **Parametric / Ratio**: unit cost × quantity  
- **Three-Point / PERT**: uses optimistic, most likely, pessimistic estimates

#### Three-point formulas｜三点估算法
Triangular:
\[
C_E = \frac{C_O + C_M + C_P}{3}
\]

Beta / PERT:
\[
C_E = \frac{C_O + 4C_M + C_P}{6}
\]

### 6.7 Determine Budget｜制定预算
Budgeting uses:
- cost estimates  
- basis of estimates  
- project schedule  
- risk register  
- business case  
- benefits management plan  
- agreements and organizational assets

### 6.8 Cost baseline and project budget｜成本基准与项目预算
Typical logic:
- Work estimates → reserve analysis → cost baseline → management reserve → project budget

### 6.9 Control Costs｜控制成本
Control costs means monitoring cost status, updating costs, and managing changes to the baseline.  
控制成本就是监测项目成本状态并对基准偏差做管理和纠正。

### 6.10 Earned Value Management (EVM)｜挣值管理
EVM integrates scope, schedule, and cost to measure performance and progress.  
EVM 把范围、进度和成本结合起来衡量项目绩效。

### 6.11 Three core EVM variables｜三大核心变量
- **PV (Planned Value)**｜计划值：本来计划应完成的价值
- **EV (Earned Value)**｜挣值：实际已完成工作的预算价值
- **AC (Actual Cost)**｜实际成本：实际花掉的钱

### 6.12 Main EVM formulas｜核心公式
- `CV = EV - AC`  → Cost Variance｜成本偏差
- `SV = EV - PV`  → Schedule Variance｜进度偏差
- `CPI = EV / AC` → Cost Performance Index｜成本绩效指数
- `SPI = EV / PV` → Schedule Performance Index｜进度绩效指数

### 6.13 Interpretation｜指标解释
- `CV > 0` good → under budget  
- `CV < 0` bad → over budget  
- `SV > 0` good → ahead of schedule  
- `SV < 0` bad → behind schedule  
- `CPI > 1` good → cost efficient  
- `SPI > 1` good → schedule efficient

### 6.14 Forecasting terms｜预测相关术语
- **BAC** = Budget At Completion｜完工预算
- **EAC** = Estimate At Completion｜完工估算
- **ETC** = Estimate To Complete｜尚需估算成本
- **TCPI** = To-Complete Performance Index｜完工绩效指数

A common lecture idea is:  
`EAC = AC + ETC`  
meaning forecast final cost = actual cost so far + remaining estimate.  
即最终成本预测 = 已发生实际成本 + 剩余完成成本。

### 6.15 Worked slide-style EVM example｜课件风格例题
Given:
- `PV = $3000`
- `EV = $2000`
- `AC = $4100`

Then:
- `CV = EV - AC = 2000 - 4100 = -2100`
- `SV = EV - PV = 2000 - 3000 = -1000`
- `CPI = EV / AC = 2000 / 4100 = 0.48`
- `SPI = EV / PV = 2000 / 3000 = 0.67`

**Interpretation｜解释**
- project is **over budget**  
- project is **behind schedule**  
- only 48 cents of value are earned per dollar spent  
- only 67% of the planned progress has been achieved

## 12. Common Trap Points｜常见易错点

1. **Zero float means critical path.**  
   **浮时为 0 就是关键路径。**

2. **CPI < 1 means cost inefficiency / over budget trend.**  
   **CPI 小于 1 表示成本效率差，存在超支趋势。**

3. **SPI < 1 means behind schedule.**  
   **SPI 小于 1 表示进度落后。**

4. **QA is about process; QC is about deliverables/testing.**  
   **QA 看过程，QC 看交付物和测试。**

5. **Predictive = clear requirements; Adaptive = uncertain requirements.**  
   **预测型适合需求清晰，自适应型适合需求不明确。**

6. **Top-down is quicker but less accurate.**  
   **自上而下估算更快，但精度较低。**

7. **AI in PM is not the same as building an AI product.**  
   **项目管理中的 AI 不等于做一个 AI 产品项目。**
